1. Overview

Skylark Zoom Services is a powerful platform that enables you to create and manage Zoom meetings with automated bot participants. The service allows you to:

  • Create Zoom meetings with customizable bot participants
  • Configure video and audio bot settings
  • Schedule meetings for specific times
  • Manage multiple meetings simultaneously
  • Track usage and meeting statistics

Note: This service requires a valid Zoom account and appropriate Zoom API credentials to function properly.

2. Getting Started

2.1 Prerequisites

Before you begin, ensure you have:

  • A valid Zoom account (Pro, Business, or Enterprise recommended)
  • Zoom API credentials (Client ID and Client Secret)
  • Access to create and manage Zoom meetings
  • A modern web browser (Chrome, Firefox, Safari, or Edge)

2.2 Account Setup

To get started:

  1. Visit https://skylarkzoom.online
  2. Create an account using the registration form
  3. Verify your email address (if required)
  4. Log in to access the dashboard

3. Adding the App

3.1 Installation Process

Step 1: Access the Dashboard

After logging in, you'll be directed to the main dashboard where you can see your usage statistics and meeting management interface.

Step 2: Configure Zoom Integration

Before creating meetings, ensure your Zoom credentials are properly configured:

  • Navigate to your account settings
  • Enter your Zoom Account ID
  • Enter your Zoom Client ID
  • Enter your Zoom Client Secret
  • Save the configuration

Step 3: Verify Connection

The system will automatically verify your Zoom credentials. If successful, you'll see a confirmation message. If there are errors, check:

  • Your Zoom account status
  • API credentials are correct
  • Required Zoom permissions are granted

Security Note: Keep your Zoom API credentials secure. Never share them publicly or commit them to version control systems.

4. Using the App

4.1 Creating a Meeting

To create a new meeting with bots:

Meeting Form Fields

Field Description Requirements
Meeting ID Your Zoom meeting ID Valid Zoom meeting ID
Meeting Password Password for the Zoom meeting Meeting password (if required)
Total Members Total number of bot participants Must be divisible by 10, cannot be zero
Video Bots Number of bots with video enabled Must be ≤ Total Members
Audio Bots Number of bots with audio enabled Must be ≤ Total Members
Name Name type for bots Indian or International
Meeting Type Type of bot participants Normal Member or Profile Pic Member
Timeout Meeting duration in seconds Default: 7200 (2 hours)

4.2 Step-by-Step Meeting Creation

  1. Enter Meeting Details: Fill in the Meeting ID and Password from your Zoom meeting
  2. Set Participant Count: Enter the total number of members (e.g., 10, 20, 30, etc.)
  3. Configure Bots: Specify how many bots should have video and audio enabled
  4. Choose Name Type: Select "Indian" for Indian names or "International" for international names
  5. Select Meeting Type: Choose between normal members or profile picture members
  6. Set Timeout: Specify how long the meeting should run (in seconds)
  7. Submit: Click the "SUBMIT" button to start the meeting

Example: To create a meeting with 20 participants where 10 have video and all have audio, set Total Members to 20, Video Bots to 10, and Audio Bots to 20.

4.3 Scheduling Meetings

To schedule a meeting for a future time:

  1. Fill in all meeting details as described above
  2. Check the "Enable Scheduling" checkbox
  3. Enter the scheduled time in IST (Indian Standard Time) format
  4. Click "SUBMIT"

The meeting will automatically start at the specified time. You can view and manage scheduled meetings in the "Scheduled Tasks" section.

5. Features and Configuration

5.1 Custom Names

You can add custom names for bot participants:

  1. Click "Add custom names" in the dashboard header
  2. Select the name type (Indian or International)
  3. Enter the custom name
  4. Click "Add Name"

Custom names will be available for use in future meetings.

5.2 Meeting Types

  • Normal Member: Bots join with default Zoom avatars and standard appearance
  • Profile Pic Member: Bots join with custom profile pictures from your uploaded collection

5.3 Usage Tracking

The dashboard displays your usage statistics:

  • Total submitted meetings
  • Remaining capacity
  • Usage percentage

Monitor your usage to ensure you stay within your plan limits.

6. Managing Meetings

6.1 Viewing Active Meetings

The "All Meetings" section displays:

  • Meeting ID
  • Total participants
  • Video and audio bot counts
  • Start time
  • Timeout duration
  • Name type
  • Meeting type

6.2 Stopping Meetings

To stop an active meeting:

  1. Locate the meeting in the "All Meetings" table
  2. Click the "Action" button in the meeting's row
  3. Confirm the action

The meeting will be immediately terminated, and all bots will disconnect.

6.3 Downloading Meeting Details

To download meeting information:

  1. Click "DOWNLOAD DETAIL'S" in the "All Meetings" section
  2. A file will be downloaded containing all meeting data

6.4 Managing Scheduled Tasks

View and manage scheduled meetings in the "Scheduled Tasks" section:

  • See all upcoming scheduled meetings
  • View scheduled time and configuration
  • Cancel scheduled meetings if needed

7. Removing the App

7.1 Stopping All Meetings

Before removing the app, ensure all active meetings are stopped:

  1. Review the "All Meetings" section
  2. Stop any active meetings using the Action button
  3. Cancel any scheduled meetings

7.2 Account Deletion

To remove the app and delete your account:

  1. Contact support at support@skylarkzoom.online
  2. Request account deletion
  3. Confirm all meetings are stopped
  4. Verify your identity (for security)

7.3 Data Removal

Upon account deletion:

  • All meeting data will be removed
  • Custom names will be deleted
  • Account credentials will be removed
  • Usage history will be cleared

Important: Account deletion is permanent and cannot be undone. Ensure you have downloaded any important data before requesting deletion.

7.4 Revoking Zoom Access

After removing the app, revoke Zoom API access:

  1. Log in to your Zoom account
  2. Navigate to Zoom App Marketplace
  3. Find "Skylark Zoom Services" in your installed apps
  4. Click "Uninstall" or "Remove"
  5. Confirm the removal

8. Troubleshooting

8.1 Common Issues

Issue: Meeting fails to start

Solutions:

  • Verify Meeting ID and Password are correct
  • Ensure the Zoom meeting exists and is accessible
  • Check your Zoom account permissions
  • Verify you haven't exceeded usage limits

Issue: Bots not joining

Solutions:

  • Check meeting settings allow participants to join
  • Verify Zoom account allows bot participation
  • Review meeting logs for error messages
  • Ensure network connectivity is stable

Issue: Authentication errors

Solutions:

  • Verify Zoom API credentials are correct
  • Check that credentials haven't expired
  • Ensure required Zoom permissions are granted
  • Regenerate API credentials if necessary

8.2 Getting Help

If you encounter issues not covered in this documentation:

  • Visit our Support Center
  • Email us at support@skylarkzoom.online
  • Include detailed error messages and steps to reproduce
