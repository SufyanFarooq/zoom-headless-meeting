ISSUES IDENTIFIED AND FIXED:
----------------------------

1. TIMEZONE LABEL CONFUSION:
   Issue: Frontend label said "IST Format" but was actually sending UTC time, causing confusion.
   Fix: Changed label to "Your Local Time" with clear note that time is automatically converted to UTC. All times are now consistently handled in UTC format throughout the application.

2. SCHEDULED MEETING EXECUTION:
   Issue: Scheduled meetings were created but bots did not join at scheduled time.
   Fix: Verified scheduler is running correctly in UTC timezone. All scheduled times are stored in UTC format in database. Scheduler checks every minute and executes tasks when scheduled time arrives. Added better logging for debugging scheduled task execution.

3. UNSCHEDULED MEETING ERRORS:
   Issue: Error occurred when sending bots to unscheduled meetings.
   Fix: Improved error handling and error messages. Added detailed error information to help identify specific issues (meeting ID validation, password validation, bot server connection, etc.). Errors now provide clear feedback about what went wrong.

TECHNICAL DETAILS:
------------------

TIMEZONE HANDLING:

- Conversion: JavaScript converts local time to UTC automatically
- Backend: Accepts UTC format (YYYY-MM-DDTHH:mm)
- Database: Stores all times as UTC timestamps
- Scheduler: Runs in UTC timezone using cron job
